  1. 上のメニュー File → Clone repository
  2. URL タブをクリック
  3. 下のURLを1つずつ入れて Clone を押す（3回繰り返す）

🌿 A. スポット編集の手順

大原則：必ずNotion DBから先に変更する
Notionが「マスター」、サイトは「コピー」です。先にサイトをいじるとデータが食い違うので絶対NG。
STEP 1Notion DBで変更

マスターDBを開く

例：

  • 新スポット追加 → 行を追加して情報入力 →「サイトに表示」ON
  • スポット削除 →「サイトに表示」OFF
  • 営業時間変更 → 該当行を編集
  • 座標修正 → 「Map / 地図」の場所を変更
STEP 2Claudeに反映を頼む
💬 こんな感じで頼む
「Notion DBの最新内容を3サイトに反映して」
「Notionに新しく追加した『○○カフェ』を3サイトに追加して」
「Notionで『サイトに表示』のチェックを外したスポットを3サイトから消して」

Claudeが日英・3サイトすべてに自動反映してくれる。

STEP 3GitHub Desktopで3サイト全部Push

スポット編集は 必ず3サイト全部 にCommit & Pushする：

  1. unplan-hakuba-guide → Commit & Push
  2. Square8-Hakuba-Guide → Commit & Push
  3. Maruhachi-Hakuba-Guide → Commit & Push

🏠 B. 宿泊ガイド・その他の編集手順

各拠点ごとに内容が違うので、対象のサイトだけ編集すればOK。

STEP 1Claudeに頼む（どの拠点か明示）
💬 こんな感じで頼む
「UNPLAN（栂池）のstayページのチェックイン時間を16時に変更して」
「丸八（岩岳）のhakubaページにアクセス情報追加して」
「Square8（岩岳）のトップ画像を新しい写真に差し替えて」
💡 「○○拠点（または○○サイト）の」と必ず最初に伝える
STEP 2GitHub Desktopで対象サイトだけPush

該当する1サイトだけCommit & Push：

  • 例：UNPLAN（栂池）のstay修正 → unplan-hakuba-guide だけPush
  • 例：丸八（岩岳）のhakuba修正 → Maruhachi-Hakuba-Guide だけPush
  • 例：Square8（岩岳）のstay修正 → Square8-Hakuba-Guide だけPush

💬 Claudeへの頼み方の例

スポット編集（必ずNotion経由）

「Notion DBに新しいスポット追加したから3サイトに反映して」
「Notionで○○の営業時間変えたから3サイト更新して」
「Notionでサイト非表示にしたスポットを3サイトから消して」

宿泊ガイドの編集（拠点ごと）

「UNPLAN（栂池）のstayの料金を○○円に変更して」
「丸八（岩岳）のhakubaにアクセス方法を追加して」
「Square8（岩岳）のトップ画像を差し替えて」

困ったとき

「○○ページに○○の記載があるか確認して」
「最近の変更履歴を教えて」

⚠️ 大事なルール

✅ ルール1：スポット編集は必ずNotion DBから

Notion DBがマスター。先にNotionを変更してから、Claudeにサイト反映を頼む。

✅ ルール2：スポット編集の変更は3サイトすべて反映

green-season（マップ）の内容は3サイト共通。Pushも3回必要。

✅ ルール3：宿泊ガイド等は拠点ごと個別

stay / hakuba / index などの拠点情報は、該当サイトだけ編集すればOK。Claudeに「どの拠点か」必ず伝える。

❌ ルール4：Netlifyは絶対使わない

「Netlify Drop」などは使わない。公開はGitHub経由のみ。

🚧 よくあるトラブル

困ったこと対処法
Pushが失敗する"Fetch origin" → "Pull origin" してからやり直し
サイトが反映されない1〜2分待つ。ブラウザで Cmd+Shift+R
Claudeが「ファイルが見つからない」と言う「書類フォルダにアクセス許可ある？」と確認
Claudeが間違った修正をした「○○が違うから直して」と指摘。または GitHub Desktopで "Discard changes" でやり直し
スポット編集なのに3サイトに反映されてないNotion DBで変更したか確認。3サイト全部Pushしたか確認

✅ 編集チェックリスト

  2. Claudeに「3サイトに反映して」と頼んだ
  3. GitHub Desktopで 3つのリポジトリ全部 をPushした
  4. 1〜2分後に3サイト公開先で反映を確認した

宿泊ガイド・その他編集（B）

  1. Claudeに「どの拠点か」を明示して頼んだ
